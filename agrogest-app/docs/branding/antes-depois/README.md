## Lacunas conhecidas

- **Antes no tema claro: não capturado.** Para trocar o tema do protótipo foi preciso clicar nas Preferências, e essa ação foi bloqueada pelo modo automático da sessão. Os pares com "antes" estão todos no escuro; o claro só existe no "depois".
- **Antes de Atividade, Mais, Início gerencial e analítico: não capturados.** Não foram refeitos para o estado anterior.
- Os prints "depois" foram feitos com "Reduzir animações" ligado no protótipo. Sem isso, as animações de entrada do Reanimated ficam presas no preview do navegador (não é defeito do app).
- Nenhum teste em aparelho real ou emulador.
